# 轻唱 QingChang

一款原生 macOS KTV 点歌台。用本地歌库按歌名、拼音或歌手点歌，演唱时看大字同步歌词、自己的音高轨迹和逐句评分。

## 安装

在 [GitHub Releases](https://github.com/W52M/QingChang/releases) 下载并解压，拖动「轻唱」到「应用程序」。当前安装包支持 Apple 芯片 Mac，要求 macOS 13 或更新版本。安装包使用临时签名，尚未经过 Apple 公证。如果 macOS 拦截，请在核对发布来源后，到「系统设置 → 隐私与安全性」查看是否有「仍要打开」。

源码可以在 Mac 上构建。安装 Xcode 命令行工具后，运行：

```sh
bash scripts/test.sh
bash scripts/build.sh
open 'dist/轻唱.app'
```

## 连接麦克风

1. 接好 USB 麦克风或无线麦克风的 USB 接收器。以 DJI Mic Mini 为例，确认接收器出现在 macOS 的「声音 → 输入」里。
2. 在轻唱打开「声音设置」，分别选麦克风和播放设备。点「开启收音」，允许权限，讲话时看输入电平。
3. 如果要听自己的声音，连接有线耳机或 USB 耳机，确认播放设备接的是耳机，再点「开启监听」。展开「回音与混响」可以调整回音量、间隔、混响场景和混响量。监听效果只作用于你听到的人声，评分使用原始收音。
4. 有断音时试「稳定」缓冲。设置里显示设备实际缓冲帧数，播放引擎运行时也显示设备报告的输出延迟。听到自己声音的总延迟还包括输入、设备及处理环节。

连接过的麦克风会保留选择。开启收音后拔掉麦克风，轻唱会停止收音并等待原设备回来。切换设备或重启会关闭人声监听。Studio Display 等扬声器只播放歌曲，麦克风继续用于评分。音箱声串入麦克风仍可能影响评分，软件目前没有声学回声消除或音箱人声扩声功能。

## 导入歌曲

发布包和仓库只提供软件与说明。歌曲、歌词、谱面、封面和 MV 由你从允许下载和本地使用的渠道准备。已有 UltraStar 歌库时，直接选包含各首歌子文件夹的根目录。

- [歌包目录和谱面格式](docs/song-pack.md)
- [交给 AI 助手整理本地歌包的提示词](docs/import-prompt.md)

麦克风数据、歌库和评分在本机处理。应用不会自动抓歌。伴奏可随歌包导入。已经有 Demucs 环境的用户也可将 Python 可执行文件的绝对路径写入 `separationPython` 偏好设置，按需在本机制作伴奏。
