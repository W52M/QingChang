# 给 AI 助手的歌库整理提示词

复制下面的提示词，填上你有权使用的文件夹和目标路径。也可以附上创作者或版权方明确允许下载和本地使用的链接。

```text
请把我提供的歌曲整理成 macOS「轻唱」可以导入的本地歌库。
素材位置：[本地目录或明确允许下载和本地使用的链接]
目标目录：[我要选择的歌库根目录]

1. 只使用我提供且有权使用的文件，或许可明确允许相应下载和使用的来源。
   若需补齐素材，先检查发布者和使用许可。遇到登录、付费、下载限制或许可不清，列为缺项。
2. 每首歌建独立子目录，使用 UTF-8 的 UltraStar chart.txt。
   按实际素材写 #TITLE、#ARTIST、#AUDIO、#BPM、#GAP。
   有同版本伴奏、MV、封面时分别添加 #INSTRUMENTAL、#VIDEO、#COVER。
   所有路径相对歌曲目录。保留原文件。
3. 按实际演唱版本整理同步汉字歌词和音符。每拍 4 格，GAP 单位毫秒，
   音高写 MIDI 值减 60。逐字比对音频；没有可靠音高的部分用 F 自由唱。
4. 检查文件可播放、谱面在曲目时长内、音符时长为正。抽听开头、副歌和结尾。
   汇报成功、待校对、缺失素材及其来源。把产物放在我的本地目录。
```
